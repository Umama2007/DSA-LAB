# Data Structures & Algorithms Lab — C++

A structured collection of my **Data Structures and Algorithms (DSA)** lab work completed in C++. This repository documents my practical learning journey through core DSA concepts, problem-solving techniques, and algorithm implementation.

Each lab contains clean, well-organized C++ solutions for the tasks assigned during the course.

## Topics Covered

* C++ fundamentals for DSA
* Arrays and strings
* Searching algorithms
* Sorting algorithms
* Recursion
* Linked lists
* Stacks
* Queues
* Trees
* Graphs
* Hashing
* Algorithm complexity and performance analysis
